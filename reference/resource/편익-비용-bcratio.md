## 비용 산식 및 근거

### ① 개발비 3억원 (1회성)

```
```

= (PM 1명 + iOS 1명 + AND 1명 + BE 1명 + AI/ML 1명 + Designer 1명) × 6개월 × 월 평균 인건비
≈ 3억원
**왜 이렇게**: 문서의 기술 아키텍처(GPS/IMU 수집, 클라우드 AI 분석, 이중 앱 구조)를 구현하려면 최소 6개월 × 6인 체제가 필요. 한국 모바일 앱 + AI 모델 개발 시세(2~5억)의 중간값. **1회성이므로 연도 배분 없이 2026년에만 계상**.

### ② 추가 구축비 4,000만원 / 유닛

```
```

= 서버 증설(1,500만) + CAC 마케팅(1,500만) + 온보딩 인프라(1,000만)
= 40,000,000원 / 1,000가족

**왜 이렇게**: 가구당 CAC 목표 15,000원 × 1,000 = 1,500만원 (문서 기재값 그대로). 추가 서버 리전·DB 증설은 AWS 기준. 이미지 예시(병원 1개소 구축비 1.15억)보다 훨씬 낮은데, **하드웨어가 없는 소프트웨어 서비스 특성**을 반영.

### ③ 운영비 4,000만원 / 유닛 / 년

```
```

= 서버·클라우드 1,800만 + AI 추론 960만 + 결제수수료 216만 
  + CS 인력 안분 600만 + 유지보수 안분 424만

**왜 이렇게**: 가구당 월 3,300원 수준의 운영 원가. SaaS 업계 표준 gross margin 60~70%에 맞춰 역산. ARPU 6,000원 대비 55% 운영비율 → 그로스 마진 45% (보수적).
